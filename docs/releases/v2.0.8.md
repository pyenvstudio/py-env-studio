# Release Notes: v2.0.8

Released February 14, 2026. Superseded by [v2.1.0](v2.1.0.md).

## Highlights

- Added the AutoResolver recovery flow for common pip and uv dependency-resolution failures.
- Added uv-backed environment and package workflows, with pip fallback when uv is unavailable.
- Added the plugin framework, lifecycle management, persisted enablement, and the plugin manager UI.
- Added plugin hooks for environment operations, package operations, application lifecycle, and scan completion.
- Added a sample plugin and dedicated plugin documentation.

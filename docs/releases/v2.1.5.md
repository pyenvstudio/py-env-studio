# Release Notes: v2.1.5

Py Env Studio 2.1.5 fixes UI state synchronization when users change the
selected environment while environment and package lists are being refreshed.

## Environment selection

- Mouse selection, keyboard selection, and selection restoration after a list
  refresh now synchronize the selected environment, recent location,
  activation control, and package context together.
- If the selected environment is deleted or no longer valid, the app clears its
  selection-dependent location and package view and disables activation.

## Package list consistency

- Package-list requests are bound to both their refresh generation and target
  environment. Results and errors from a previous selection are discarded.
- An open package pane refreshes when the selected environment changes.
- Package row actions are ignored if the selected or displayed environment no
  longer matches the environment represented by those rows.

## Validation

The regression tests cover delayed package results, pane refresh on selection
change, keyboard selection, refresh restoration, deleted-environment cleanup,
and stale package callbacks. The focused UI-state and progress test run passed
23 tests.
